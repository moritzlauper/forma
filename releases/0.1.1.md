# FORMA 0.1.1 — public preview

Download **forma-0.1.1.zip**, extract it, open `chrome://extensions`, enable Developer mode, and choose **Load unpacked** → the extracted `dist` folder.

For an existing installation, rebuild or replace the extension files, reload FORMA in Chrome, and refresh open shop tabs. Existing browser profiles and locally remembered API keys are preserved. Newly installed copies start with an empty profile.

## Included

- Local clothing fit comparisons with per-dimension explanations.
- Automatic detection of supported size charts, including transposed XS/S/M/L charts without a “Size” heading.
- Regression fix for the SCRT Android Dreams Hoodie chart shown in the bug report: pit-to-pit width and HPS body length are parsed separately.
- English interface and simple English/German profile descriptions.
- Broad, clearly marked measurement estimates from height and weight; measured and locked values take precedence.
- Optional cached AI extraction with Claude Haiku 5.5 or local Ollama, plus a request limit.
- API keys remembered locally, excluded from profile exports, with a Forget action.
- Dedicated toolbar icon and simplified wordmark.

## Verification and limits

TypeScript, 22 automated tests and the production build passed locally. The SCRT regression is tested against a fixture transcribed from the screenshot, not a verified live browser session. Image charts/OCR and calibrated virtual try-on are not included. Measurement estimates are unvalidated starting heuristics, not precise body measurements.

This is a **GitHub preview release**, not a Chrome Web Store listing.
